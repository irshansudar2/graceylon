# Graceylon — About Page Master Brief (for AI use)

## 0. How To Use This File
- Purpose: complete content, structure, SEO and image prompts for the Graceylon About page (graceylon.com, Shopify).
- Replace every `[bracketed placeholder]` with verified facts before publishing. Never invent facts to fill them.
- Do not publish unverified claims (organic, single-origin, hand-harvested, charitable percentages, certifications). Include only if the owner supplies proof and scope.
- Tone: poetic, quiet luxury, heritage, sensory. Short lines. Poetry creates desire; real details create trust.
- Do not present AI-generated images as real estates, makers, or products.
